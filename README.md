# Diwali Sales Data Analysis

Applied Data Science coursework (Module: CC5061NI) analyzing a Diwali sales
transaction dataset using Python.

## Contents

- `Tulip_Poudel_24046660.ipynb` — main analysis notebook covering:
  - Data understanding (sources, types, challenges)
  - Data preparation & cleaning
  - Exploratory data analysis
  - Statistical testing
- `DiwaliSalesData_264932.csv` — dataset used by the notebook (add this if it's not already in your zip; the notebook expects it in the same folder)

## Tools used

- Python (pandas, numpy)
- matplotlib / visualization libraries
- Jupyter Notebook

## How to run

1. Clone this repo
2. Install dependencies: `pip install pandas numpy matplotlib`
3. Open `Tulip_Poudel_24046660.ipynb` in Jupyter and run all cells
